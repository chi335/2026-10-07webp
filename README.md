# 📘 Chapter 06. 자바스크립트 언어 기본

## 1. 자바스크립트 개요

### 1.1 자바스크립트란?
- **역사**: 1995년 Netscape사에서 웹 페이지에 동적인 기능을 추가하기 위해 개발.
- **특징**:
  - **인터프리터 언어**: 별도의 컴파일 과정 없이 웹 브라우저의 자바스크립트 엔진에 의해 즉시 실행.
  - **C 언어 구조 차용**: 문법 구조가 C/C++/Java와 유사하여 배우기 쉬움.
  - **HTML 내장**: HTML 문서 안에 스크립트 코드를 직접 작성 및 동적 처리 가능.

### 1.2 웹 페이지에서 자바스크립트의 역할
1. **사용자 입력 처리 및 계산**: 마우스/키보드 이벤트 처리 및 연산 수행.
2. **웹 페이지 내용 및 모양의 동적 제어**: HTML 태그 속성, 텍스트, CSS 스타일을 실시간 변경.
3. **브라우저 제어**: 윈도우 크기 조절, 새 창 열기/닫기, 페이지 이동(히스토리 관리).
4. **웹 서버와의 통신 및 고급 API**: AJAX를 통한 서버 통신, Canvas 그래픽, 로컬/세션 스토리지, 위치 정보(Geolocation) 활용 등.

---

## 2. 자바스크립트 코드 작성 위치

자바스크립트 코드는 크게 **4가지 위치**에 작성할 수 있습니다.

| 구 분 | 작성 방법 | 코드 예시 |
| :--- | :--- | :--- |
| **1. HTML 태그의 이벤트 리스너** | 태그 속성에 직접 자바스크립트 작성 | `<img src="apple.jpg" onmouseover="this.src='banana.jpg'">` |
| **2. `<script>` 태그 내 작성** | HTML 문서의 `<head>` 또는 `<body>` 내부 | `<script> alert('Hello'); </script>` |
| **3. 외부 자바스크립트 파일** | 별도의 `.js` 파일로 작성 후 불러오기 | `<script src="script.js"></script>` |
| **4. URL 부분 (href 속성)** | `javascript:` 슈도 프로토콜 사용 | `<a href="javascript:alert('클릭!');">클릭</a>` |

---

## 3. 자바스크립트 입출력 및 다이얼로그

### 3.1 HTML 콘텐츠 직접 출력
- **`document.write()` / `document.writeln()`**: 웹 페이지 본문에 HTML 콘텐츠를 직접 삽입하여 출력.
```javascript
document.write("<h3>Welcome!</h3>");
document.write("<mark>결과 값입니다.</mark>");
```

### 3.2 자바스크립트 다이얼로그 (Dialog)
1. **`prompt("메시지", "기본값")`**: 사용자로부터 문자열을 입력받는 다이얼로그.
   - [확인] 클릭 ➔ 입력받은 문자열 리턴
   - [취소] 또는 닫기 ➔ `null` 리턴
2. **`confirm("메시지")`**: 확인/취소 선택을 받는 다이얼로그.
   - [확인] ➔ `true` 리턴 / [취소] ➔ `false` 리턴
3. **`alert("메시지")`**: 사용자에게 알림 메시지를 보여주는 경고 창.

## 4. 식별자, 변수 및 데이터 타입

### 4.1 식별자 (Identifier) 규칙
- 변수, 상수, 함수의 이름.
- **첫 번째 문자**: 알파벳(A-Z, a-z), 언더스코어(`_`), 달러 기호(`$`)만 가능 (숫자로 시작 불가).
- **대소문자 구분**: `Sum`과 `sum`은 서로 다른 식별자.
- 예약어(키워드) 사용 불가.

### 4.2 변수 선언 키워드
- **`let`**: 블록 스코프(Block Scope) 지역 변수 선언 (권장).
- **`const`**: 상수 선언 (값 재할당 불가).
- **`var`**: 함수 스코프(Function Scope) 변수 선언 (구버전 호환용).

### 4.3 데이터 타입 (Data Types)
- **기본 타입 (Primitive Types)**:
  - `Number` (정수, 실수 등 수치형)
  - `String` (문자열)
  - `Boolean` (`true` / `false`)
  - `null` (값이 없음을 명시적으로 지정)
  - `undefined` (변수가 선언되었으나 값이 할당되지 않은 상태)
- **객체 타입 (Object Type)**:
  - 배열, 객체, 함수 등

## 5. 연산자 (Operators)

| 연산자 종류 | 주요 연산자 | 설명 및 특징 |
| :--- | :--- | :--- |
| **산술 연산자** | `+`, `-`, `*`, `/`, `%` | `/` 연산 시 정수 나누기도 **실수 결과** 반환 (예: `32/10` ➔ `3.2`) |
| **증감 연산자** | `++`, `--` | 전위(`++a`), 후위(`a++`)에 따라 평가 시점이 다름 |
| **대입 연산자** | `=`, `+=`, `-=`, `*=`, `/=` 등 | 변수에 값을 저장하거나 복합 연산 수행 |
| **비교 연산자** | `>`, `<`, `>=`, `<=`, `==`, `!=`, `===`, `!==` | `===`는 값과 데이터 타입이 모두 같은지 비교 |
| **논리 연산자** | `&&` (AND), `\|\|` (OR), `!` (NOT) | 조건들의 논리 조합 평가 |
| **비트 연산자** | `&`, `\|`, `^`, `~`, `<<`, `>>`, `>>>` | 비트 단위 연산 및 시프트 수행 |
| **문자열 연산자**| `+`, `+=` | 문자열 연결. 피연산자 중 하나가 문자열이면 결합 수행 |
| **조건 연산자** | `조건식 ? 참일때 : 거짓일때` | 삼항 연산자 |

## 6. 제어문 (Control Flow)

### 6.1 조건문 (Conditional Statements)
- **`if / else if / else`**
```javascript
let score = 85;
if (score >= 90) {
    document.write("A 학점");
} else if (score >= 80) {
    document.write("B 학점");
} else {
    document.write("C 학점 이하");
}
```

- **`switch` 문**
  - `case` 값에는 변수나 식 사용 불가 (단순 값/리터럴만 사용).
  - `break` 문을 만나야 switch 블록을 탈출.

### 6.2 반복문 (Loop Statements)
- **`for` 문**: 정해진 횟수만큼 반복
- **`while` 문**: 조건이 참인 동안 반복
- **`do-while` 문**: 최소 1회 실행 후 조건 검사

### 6.3 반복문 제어 키워드
- **`break`**: 감싸고 있는 가장 가까운 반복문을 즉시 탈출.
- **`continue`**: 현재 반복의 남은 코드를 건너뛰고 다음 반복으로 이동.

## 7. 함수 (Functions) 및 전역 함수

### 7.1 함수 선언 및 호출
```javascript
// 함수 정의
function adder(a, b) {
    let sum = a + b;
    return sum; // 결과 반환
}

// 함수 호출
let result = adder(10, 20); // result = 30
```

### 7.2 자바스크립트 주요 전역 함수 (Global Functions)
- **`eval(string)`**: 문자열로 된 자바스크립트 식 또는 문장을 수식으로 계산하여 실행.
- **`parseInt(string)`**: 문자열을 정수로 변환.
- **`parseFloat(string)`**: 문자열을 실수로 변환.
- **`isNaN(value)`**: 값이 숫자가 아닌지(`NaN`: Not a Number) 여부 확인 (숫자가 아니면 `true`).
- **`isFinite(value)`**: 유효한 숫자이면 `true`, 무한대(`Infinity`)이면 `false` 반환.

# 🐙 Git & GitHub 협업 가이드

## 1. Git vs GitHub 차이

| 구분 | Git | GitHub |
| :--- | :--- | :--- |
| **개념** | **내 컴퓨터 관리 프로그램** | **인터넷 클라우드 사이트** |
| **역할** | 로컬 컴퓨터에서 코드 변경 이력 기록 및 관리 | 로컬에 기록된 코드를 웹상에 올려 팀원들과 공유 및 협업 |

---

## 2. 핵심 용어 정리

- 📌 **Issue (이슈)**: 프로젝트 시작 전 "로그인 화면 만들기", "회원가입 버그 수정"처럼 해야 할 일이나 버그를 적어두는 게시판.
- 📂 **Repository (저장소)**: 팀의 프로젝트 파일들과 전체 역사가 통째로 저장되는 클라우드상의 메인 폴더.
- 🌿 **Branch (브랜치)**: 메인 원본 코드(`main`)를 직접 변경하지 않고, 원본을 복사해와 독립적으로 안전하게 작업할 수 있는 가지(작업 공간).
- 📩 **Pull Request / PR (풀 리퀘스트)**: 내 브랜치에서 코딩을 마치고 깃허브에 올린 후, "내 코드를 메인 원본(`main`)에 합쳐주세요!"라고 요청하는 공식 문서.
- 🔍 **Review (코드 리뷰)**: 팀원이 올린 PR을 다 함께 읽어보고 이상이나 에러가 없는지 피드백(댓글)을 남기는 과정.
- 🔀 **Merge (머지)**: 코드 리뷰 검토가 완료되면 PR을 승인하여 메인 원본 코드에 최종 병합하는 단계.

---

## 3. 팀장(Leader) 세팅 가이드

1. **새 레포지토리 생성**: GitHub 우측 상단의 `+` 버튼 ➔ `New repository` 클릭 후 이름 및 설명 작성.
2. **초기 파일 설정**: `Add a README file` 체크 및 개발 환경에 맞는 `.gitignore` 템플릿 추가 ➔ `Create repository` 클릭.
3. **팀원 초대**: `Settings` ➔ `Collaborators` ➔ `Add people` 버튼을 눌러 팀원의 GitHub ID 또는 이메일 검색 후 초대.
4. **브랜치 보호 규칙 설정 (권장)**:
   - `Settings` ➔ `Branches` ➔ `Add branch protection rule` 클릭.
   - `main` 브랜치에 직접 푸시하지 못하도록 `Require a pull request before merging` 옵션을 활성화하여 코드가 꼬이는 것을 방지.

## 4. 팀원(Member) 세팅 및 작업 가이드

### 1단계: 초대 수락 및 레포지토리 클론 (Clone)
팀장의 초대를 수락한 뒤 레포지토리 URL을 복사하여 터미널에 입력:
```bash
git clone https://github.com/KimSeungHo23/test.git
```

### 2단계: 작업용 브랜치 생성 및 이동
클론한 폴더로 이동(`cd 폴더명`) 후, 기능 단위의 새 브랜치 생성:
```bash
cd test
git checkout -b feature/hello.html
```

### 3단계: 코드 작성 및 로컬 커밋
코드 수정 완료 후 변경된 파일을 스테이징하고 커밋:
```bash
git add .
git commit -m "인사말 파일 추가"
```

### 4단계: 원격 저장소 푸시 (Push)
내 로컬 브랜치의 작업 내역을 GitHub 원격 저장소로 업로드:
```bash
git push origin feature/hello.html
```

### 5단계: Pull Request (PR) 작성
GitHub 웹 페이지 접속 ➔ 상단의 `Compare & pull request` 버튼 클릭 ➔ 작업 내용을 작성하고 PR 제출.

## 6. 슬랙(Slack) 및 지라(Jira) 연동

### 📢 슬랙(Slack) 연동
1. **GitHub for Slack 앱 설치**: 슬랙 앱 디렉토리에서 GitHub 앱 설치.
2. **채널 연동 명령어**:
   ```bash
   /github subscribe 조직명/레포지토리이름
   # 예시: /github subscribe KimSeungHo23/test
   ```
3. **알림 설정**: `/github settings` 명령어로 필요한 알림 세부 설정.

### 📋 지라(Jira) 연동
1. **GitHub for Jira 앱 설치**: Jira 프로젝트 설정 ➔ Apps ➔ `GitHub for Jira` 검색 및 설치.
2. **조직 연동**: 지라 설정 화면에서 GitHub 계정 및 협업 레포지토리 연결.
3. **이슈 키 포함 커밋**: 커밋 메시지 또는 PR 제목 앞에 지라 이슈 번호(예: `PROJ-123`) 명시.
   ```bash
   git commit -m "PROJ-123: 메인 페이지 HTML 레이아웃 작성"
   ```
